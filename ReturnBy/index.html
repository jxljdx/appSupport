Return By

App Support

Return By helps you save return deadlines from screenshots and receipts, review key details before saving, and stay ahead of refund windows with reminders.

Use this page as your App Store Support URL.

Need help?

  • If OCR misses a date or amount, open the review step and correct the fields before saving.
  • If reminders do not appear, check both Notifications and Reminders permissions in iPhone Settings.
  • If an imported backup does not recreate alerts automatically, open the record and save reminders again on this device.

Support contact

Response time: usually within 2 business days.

Frequently asked questions

  • Do I need an account? No. Return By works without account signup, inbox access, or merchant integrations.
  • Where is my data stored? Return records are stored locally on your device. JSON backup export is optional and created only when you choose to export.
  • How do reminders work? Return By can save reminders to Apple Reminders and also schedule app alerts before the deadline.
  • Can I move my data to another device? Yes. Export a JSON backup from Settings, then import it on the new device and re-save reminders there.
