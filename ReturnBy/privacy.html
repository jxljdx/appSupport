Return By

Privacy Policy

Return By is designed to be local-first and lightweight.

Data we collect

Return By does not require account creation and does not intentionally collect personal account data for core app use.

How data is used

  • Return records, notes, and reminder preferences are stored locally on your device.
  • Photos and receipt images are used only so the app can extract return details and help you save a record.
  • Text recognition for screenshots and receipts is performed on-device using Apple system frameworks.
  • Notification and Reminders permissions are used only if you choose to save reminder alerts.
  • Optional JSON exports are created only when you choose to export your own data.

Third parties

Based on the current app setup, Return By does not use third-party advertising SDKs or third-party analytics SDKs.

In-app purchases, if offered, are processed by Apple using StoreKit and your Apple account.

Your choices

  • You can deny or revoke Camera, Photos, Notifications, or Reminders permissions in iPhone Settings.
  • You can delete local records inside the app or remove the app to delete local data stored on your device.
  • You can export your records as JSON when you want a portable backup.

Return By

隐私政策

Return By 是一款本地优先、尽量轻量的应用。

我们收集的数据

Return By 不要求注册账号，核心使用流程也不会主动收集账号类个人数据。

数据如何使用

  • 退货记录、备注和提醒偏好默认保存在你的设备本地。
  • 照片和小票图片只用于提取退货相关信息，帮助你保存记录。
  • 截图和小票的文字识别通过 Apple 系统框架在设备本地完成。
  • 通知权限和提醒事项权限只会在你选择保存提醒时使用。
  • JSON 导出是可选的，只有在你主动导出时才会生成你的数据备份。

第三方服务

基于当前 app 结构，Return By 不使用第三方广告 SDK，也不使用第三方分析统计 SDK。

如果提供应用内购买，支付流程由 Apple 通过 StoreKit 和你的 Apple 账户处理。

你的选择

  • 你可以在 iPhone 系统设置中拒绝或撤销相机、照片、通知和提醒事项权限。
  • 你可以在 app 内删除本地记录，或直接删除 app 来移除设备上的本地数据。
  • 如果你需要可迁移备份，可以主动导出 JSON 文件。
