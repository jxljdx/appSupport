# Content Source

Page and article copy is stored here before it is converted to WordPress
blocks and a WXR import file.

Each content entry must define:

- locale
- stable slug
- page title
- SEO title and description
- target user intent
- Studio or App content scope
- App key for product-specific pages
- canonical counterpart in the other locale
- visible answer summary
- internal links
- App Store call to action where the page belongs to an App
