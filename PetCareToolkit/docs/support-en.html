❓ Frequently Asked Questions

How do I add a new pet?
Tap the "+" button on the main screen, then fill in your pet's information including name, species, breed, and other details.
How does nutrition calculation work?
Our nutrition calculator uses veterinary-approved formulas based on your pet's weight, age, activity level, and life stage to calculate daily calorie requirements.
Is my data synced across devices?
Your data stays on your device. You can back up or move your data with JSON export and import when needed.
What premium features are available?
Premium features include unlimited pets, professional health reports, weight trend charts, nutrition tools, medication calculation, and advanced care workflows.
How do I restore my premium purchase?
Go to Settings → Premium Features → Restore Purchase. Make sure you're signed in with the same Apple ID used for the original purchase.

🛠 Troubleshooting

App is crashing or not responding

Try these steps:

  1. Force close the app and restart it
  2. Restart your device
  3. Make sure you have the latest version installed
  4. If the problem persists, contact us with details about when the crash occurs
Data not syncing properly

If your data did not move as expected:

  1. Open Settings inside the app
  2. Use the JSON export feature to create a backup file
  3. On the destination device, use JSON import and select that file
  4. If import fails, contact us with the app version and what step failed
