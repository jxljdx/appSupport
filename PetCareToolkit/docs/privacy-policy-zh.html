隐私政策

生效日期：2026年4月7日

最后更新：2026年4月7日

摘要：宠物护理工具箱在设计时充分考虑隐私保护。我们不会收集、出售或分享您的个人信息。除非您主动导出数据，否则宠物数据默认只保存在您的设备本地。

1. 我们收集的信息

宠物护理工具箱在您的设备本地收集和存储以下信息：

  • 宠物信息：您提供的宠物姓名、品种、年龄、体重等基本信息
  • 健康记录：疫苗接种记录、医疗检查、用药记录和健康笔记
  • 体重记录：体重跟踪数据和测量值
  • 应用偏好：语言设置、单位制（公制/英制）和应用配置

2. 信息使用方式

您的信息仅用于：

  • 在应用内提供宠物护理管理功能
  • 计算营养建议和药物剂量
  • 生成健康报告和跟踪图表
  • 发送提醒通知（如果启用）
  • 在您选择备份或迁移时，通过 JSON 文件导出或导入数据

3. 数据存储和安全

  • 本地存储：所有数据主要保存在您的设备本地
  • 手动导出：如果您导出数据，只有在您主动操作时才会生成 JSON 文件，供您自行备份或迁移
  • 无第三方服务器：我们不在任何第三方服务器或云服务上存储您的数据
  • 加密保护：数据使用Apple内置的安全和加密协议进行保护

4. 数据共享

我们不会向第三方共享、出售或转让您的个人信息。

  • 没有广告网络或分析服务可以访问您的数据
  • 没有可能访问您宠物信息的第三方集成
  • 您的数据保持私有，完全由您控制

5. 您的权利和控制

您对自己的数据拥有完全控制权：

  • 访问：直接在应用内查看您的所有数据
  • 修改：随时编辑或更新任何信息
  • 删除：通过应用删除单条记录或所有数据
  • 导出：您可以在需要时将数据导出为 JSON 文件
  • 导入：您可以自行决定是否导入之前导出的 JSON 备份

6. 第三方服务

宠物护理工具箱使用以下Apple服务：

  • 本地通知：用于提醒和警报（如果允许）
  • 相机/照片库：用于宠物照片（如果允许）
  • StoreKit：用于通过 Apple 处理高级版购买、恢复购买和权益校验

这些服务受Apple隐私政策管辖。

7. 儿童隐私

宠物护理工具箱不会故意收集13岁以下儿童的个人信息。该应用专为各年龄段的宠物主人和护理者设计，但不收集特定年龄的数据。

8. 政策变更

我们可能会不时更新此隐私政策。我们将通过应用或此网页通知用户任何重大变更。您在此类变更后继续使用应用即表示接受更新后的政策。
